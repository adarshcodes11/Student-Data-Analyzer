# Student-Data-Analyzer
#  Student Performance Analyzer

A simple Python project to **store, analyze, and visualize student marks** using CSV files and graphs.

---

##  Features

*  Input student names and marks
*  Save data to a CSV file
*  Calculate:

  * Average marks
  * Highest scorer (Topper)
  * Lowest scorer
*  Assign grades (A, B, C, Fail)
*  Visualize data using a bar chart

---

##  Technologies Used

* Python
* CSV module
* Matplotlib

---

##  How It Works

1. User enters number of students
2. Inputs student names and marks
3. Data is stored in a file named **students.csv**
4. Program performs analysis
5. Displays results in terminal
6. Shows a bar graph of student performance

---



##  Example Output

```
--- Analysis ---
Average Marks: 78.5
Topper: Rahul - 95
Lowest: Aman - 45
```

---

##  Grade System

| Marks Range | Grade |
| ----------- | ----- |
| 90+         | A     |
| 75-89       | B     |
| 50-74       | C     |
| Below 50    | Fail  |
